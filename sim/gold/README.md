# 正解（gold）の付け方

`grarec_transcribe_tool/全班_文字起こし結果/班<g>_文字起こし_時系列.txt` を読んで、班ごとに `班<g>.csv` を作る。
まずは2〜3班でOK（例：班1・班5・班32）。時刻は、文字起こしの最初の行を0分とした「分」（小数OK）。

| 列 | 書くこと |
|---|---|
| start_min | その場面が始まった時刻（分） |
| end_min | 終わった時刻（分） |
| kind | topic（話題）／ difference（意見が分かれた）／ question（答えが出ないまま残った問い）／ agreement（決まったこと） |
| label | その場面を短く（10〜25字）。カードと照らすので、話し言葉に近い言い方がよい |

- topic は「話題が切り替わったら1行」。重なってもよい
- AIのカードを見る前に付けること（見てから付けると、カードに引っ張られる）
- 例は `班_example.csv`

# GraRec インターフェースのオフライン・シミュレーション

既存の音声・文字起こしデータを使って、「どんなカードが・いつ・何枚出て・トレイでどう動くか」と
「話のバランスと偏りのお知らせ」を、設定を変えながら総当たりで比べるためのスクリプト一式。
**オフラインで分かるのは「画面にこう出るはず」まで。** 参加者が実際に気づいたか・行動が変わったかは学内実験でしか分からない。

## いいグループワークの定義（2026-10-06 合意）と指標

| # | 状態 | 観点 | 指標（スクリプト） |
|---|---|---|---|
| 1 | みんなの声が場に出ている | 発話量・参加促進 | 偏りの時間帯にお知らせが出た割合／出るまでの時間／偏っていないのに出た回数（sim_balance.py） |
| 2 | 今なにを話しているか分かる | 議論構造・整理 | 正解の話題をカードで拾えた割合／話題が出てからカードまでの時間（eval_gold.py）、同じ話題の重複（sim_tray.py） |
| 3 | 違う見方が拾われる | 他者の意見 | 正解の「意見が分かれた場面」を拾えた割合（eval_gold.py）、ちがい・ひとことだけ出た の割合（sim_tray.py） |
| 4 | 次に進むきっかけがある | 進行 | 正解の「残った問い」「決まったこと」を拾えた割合（eval_gold.py） |
| 5 | 話し合いの邪魔をしない | 安心・負担 | 10分あたりの枚数・トレイの最大枚数・置かれないまま入れ替わった割合（sim_tray.py）、お知らせの回数（sim_balance.py） |
| 6 | AIが勝手に足さない | 補完であって代替でない | 引用文が文字起こしに含まれる割合、キーワードの文字が文字起こしに出てくる割合（sim_tray.py） |

測れないもの：自己の考えへの気づき、実際の気づき・行動の変化。

## 実行手順（grarec_light フォルダで、.venv を有効にして）

```
python sim/sim_balance.py                 # API不要。数秒で終わる → sim/out/balance_results.*
python sim/sim_cards.py --dry-run         # APIを何回呼ぶか・費用の目安
python sim/sim_cards.py                   # カードを作る（途中で止めても続きから）→ sim/out/cards/
python sim/sim_tray.py                    # API不要 → sim/out/tray_results.*
python sim/eval_gold.py                   # 正解（sim/gold/）を作ったあと → sim/out/gold_results.json
python sim/build_dashboard.py             # 結果を1枚のHTMLにまとめる → sim/out/dashboard.html
```

## 比べている設定

- カード（sim_cards.py の VARIANTS）：間隔（3→10分／3分／5分／10分）、1回の上限（4／6／8枚）、選び方（今のルール／問い・ちがいを優先しない）。各2回ずつ実行して揺れも見る
- トレイ（sim_tray.py）：人の置き方の仮定（誰も置かない／毎回1枚置く／毎回2枚置く）
- お知らせ（sim_balance.py）：指標（エントロピー／ジニ係数）×しきい値4段階×見る幅（5／10／15分）×「話していない人」の線（なし／3%／5%）×閉じた後の間隔（3／5／10分）＝216通り

## 仮定と限界（結果を読むときの注意）

- 7/15は量子力学・デザイン思考の授業。課題シートの授業で同じカードが出るとは限らない
- 7/15の録音には15〜20%の抜けがあり、その部分の発言はカードにならない
- お知らせの「本当の偏り」は、直近10分の正規化ジニ係数≥0.40 または誰かが5%未満、を2分未満の切れ目はつなげたうえで2分以上続いた時間帯と決めた（判定の設定とは別の物差し。ただし、この決め方に近い設定ほど有利になる）
- お知らせの設定の選び方：まず定義#5・#1の線（仮）＝偏っていないのに出る0.5回/時以下・お知らせ4回/時以下・出るまで中央値5分以内・最長10分以内、を満たすもの → 拾えた割合が高い → 回数が少ない → 早い。1位とほぼ同じ成績（回数が1.1倍以内）なら、今の設定から変える所が少ないものを「候補」にする。線の数字は sim_balance.py の先頭で変えられる
- 合成シナリオは発話の長さ・順番を乱数で作ったもの。実録音（interview_full.rttm）は pyannote の推定で、話者の正解ではない
- お知らせは60秒で閉じられる、と仮定している
- 人がカードをシートに置くかどうかは分からないので、置き方は3通りの仮定で幅を見る
- 「似た内容」の判定（eval_gold.py）は文字のバイグラムの重なりで、粗い。拾えた例・拾えなかった例を目で確かめること
